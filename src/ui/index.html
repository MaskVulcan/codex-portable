    连接用户浏览器

    复用 Chrome / Edge 登录状态，采集帖子、评论与截图。

    1. 打开浏览器扩展管理页，启用“开发者模式”。Chrome 地址为 chrome://extensions，Edge 地址为 edge://extensions。
    2. 点下面“打开扩展文件夹”，在浏览器选择“加载已解压的扩展”，选中 browser-extension 文件夹。只需首次操作。
    3. 打开已登录的小红书网页，点扩展图标，粘贴配对信息并连接。

    浏览器会显示调试提示，采集时请保留标签页。遇到登录、验证码或访问频繁，请在网页处理后继续。扩展只连接本机；配对信息请保密。

    帮助与数据

    拖文件或粘贴截图 → 说要做什么 → 打开本次结果

    每次任务会创建原件快照和处理副本，结果分别放在“输出”下的新目录。结果卡可打开、另存、打包文件，或恢复原件副本。

    任务显示“等你回答”时，请在该对话的绿色问题卡里回答。连接慢时可以停止，再换线路重试。深度处理（xhigh）可能需要更多等待时间。

    关闭主窗口后，猫和托盘继续提醒；右键猫选择“退出”可真正结束程序。Ctrl+Alt+P 打开快捷聊天。

    已归档对话可在左侧“最近对话”下拉中找回。目录被移动后，错误卡的“重新定位工作目录”能接着原对话工作。

    备份包含个人设置和令牌，请存到你自己的位置；诊断文件仅含版本和错误分类，不包含令牌、文件内容或对话正文。

    先完成第一件小事

    不用设置模型，直接给文件、说要求。

    1. 结果放在哪里？

      选一个普通工作文件夹，每次结果会放进它的“输出”目录。

    2. 把文件交给我

      用 ＋、拖放或 Ctrl+V 粘贴截图。我们会保留原件副本。

    3. 说说想得到什么

      例如“把这份材料整理成一页 Word 摘要”。也可以用“常用任务”。
